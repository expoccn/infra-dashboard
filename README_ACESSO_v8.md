# Claro DC-RJO-AM — Frontend v8

Esta versão refina exclusivamente a experiência de autenticação mantendo a lógica e as demais telas da v7.

Principais pontos:
- login institucional fixo em tema escuro/vermelho;
- background full-screen em proporção 16:9, sem divisão lateral;
- seletor de tema removido das telas de autenticação;
- seletor claro/escuro preservado após login;
- CCN Automação discreta e protegida contra corte;
- `/alterar-senha` usa a mesma composição;
- rotas, autenticação e componentes operacionais preservados.
